# Brand marks

**The avatar is `shamash-avatar.png`** — the robot-candle mascot on the
terracotta ground, 1024×1024, drawn well inside the inscribed circle so a
circular crop (WhatsApp, GitHub) never clips it. This file is what every new
user is sent at install stage 9c to set as their agent's profile picture.

| File | What it is | Where it's used |
|---|---|---|
| **`shamash-avatar.png`** | **The robot-candle on terracotta. THE avatar.** | Stage 9c → the user's agent profile picture |
| `shamash-mascot.png` | The same mascot, transparent background | The welcome PDF cover (embedded); any future composition |
| `shamash-candle-warm.png` | Legacy: the candle alone on terracotta | Retired avatar, kept for history |
| `shamash-robot-candle-warm.png` | Legacy companion art | — |
| `shamash-robot-candle-dark.png` | Legacy companion art, dark ground | — |

Provenance: the mascot is owner-chosen artwork (2026-08-05), cut from its
original background and composed by repo tooling; the legacy marks are
generated by `python scripts/build_brand.py`, which now builds only them.

The warm ground remains deliberate and not a style preference: a lone flame
on black reads as a memorial candle, and this is a working assistant.
Anything used as a profile picture sits on the warm terracotta.
