# Brand marks

Three squares, 1024×1024, rebuilt with `python scripts/build_brand.py [size]`.
Everything sits inside the central 84%, so a circular crop — WhatsApp, GitHub —
never clips it.

| File | What it is | Where it's used |
|---|---|---|
| **`shamash-candle-warm.png`** | **The candle alone, on the terracotta ground. This is the avatar.** | Sent to every new user at install stage 9c, to set as their agent's profile picture |
| `shamash-robot-candle-warm.png` | The robot standing in the candlelight, same ground | Alternate avatar; kept because it pairs with the cover |
| `shamash-robot-candle-dark.png` | The same robot on the deep ground | Only where the surrounding UI is already dark — the welcome cover |

The warm ground is deliberate and not a style preference: a lone flame on black
reads as a memorial candle, and this is a working assistant. Anything used as a
profile picture uses the warm ground.
